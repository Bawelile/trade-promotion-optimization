# Trade Promotion Analytics & Lift Modelling Pipeline

Predicts incremental promotional lift by retail banner, product, and promotional 
mechanic — separating true incrementality from pulled-forward demand. Built on a 
Bronze/Silver/Gold Medallion architecture using PySpark, Spark SQL, and Delta Lake, 
with an XGBoost lift model, SHAP explainability, and a promo ROI estimator for 
commercial planning teams.

**Stack:** PySpark · Spark SQL · Delta Lake · XGBoost · SHAP · MLflow · Databricks-compatible
